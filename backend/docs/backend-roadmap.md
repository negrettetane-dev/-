# 后端路线图

## 当前阶段：多城市比赛演示版

- 统一支持北京、厦门、福州三座城市。
- 提供城市配置、交通态势、趋势预测、路径推荐、预警和 What-If 推演。
- 所有演示数据显式标注为 `simulation`，接口结构保持可替换。

## 下一阶段：真实数据增强

- 接入高德路况、路径规划和天气接口。
- 将仿真数据迁移到 PostgreSQL/PostGIS。
- 使用历史天气和交通数据训练可解释的拥堵预测模型。
- 增加 Redis 缓存和数据源健康状态。

## 决赛展示增强

- 增加跨城市运行指标对比。
- 增加重大活动、暴雨积水和桥隧事故等标准化治理剧本。
- 完善演示录像、作品说明书和答辩讲稿中的数据来源说明。
