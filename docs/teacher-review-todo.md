# 老师展示后待完善待办清单

> 本清单根据老师展示后的反馈和当前整理的需求编写，按实现复杂程度及依赖关系排序。
>
> 标记说明：`P0` 为核心流程补齐，`P1` 为体验和业务闭环，`P2` 为数据与运营能力，`P3` 为管理端全面完善。

## 一、总体目标

- [ ] 补齐市民端路线、导航、无障碍、停车、充电和积分兑换的核心流程。
- [ ] 将停车场、充电桩、收费、拥堵等演示数据替换为真实数据，或接入字段结构一致且有更新时间的动态模拟数据。
- [ ] 建立管理端处理、用户端反馈、状态同步的业务闭环。
- [ ] 完善管理端各模块的操作、异常处理、权限和日志能力。

## 二、P0：核心功能补齐

### 1. 途经点

- [ ] 支持新增、删除和排序多个途经点。
- [ ] 重新规划包含途经点的完整路线。
- [ ] 地图区分显示起点、途经点和终点。
- [ ] 处理地点无法识别、重复地点和路线规划失败。
- [ ] 从路线规划页进入导航页后保留途经点信息。

**验收标准：** 可完成“起点 → 多个途经点 → 终点”的规划，调整途经点顺序后路线同步更新。

### 2. 导航多路线

- [ ] 同时展示多条可选路线。
- [ ] 每条路线显示距离、预计时间、主要道路、拥堵状态和是否收费。
- [ ] 支持“推荐路线、最快路线、最短路线”等标识。
- [ ] 支持切换路线，并同步更新导航详情和预计到达时间。

**验收标准：** 用户能比较不同路线的距离和时间，开始导航后使用的是选中的路线。

### 3. 分阶段导航

- [ ] 先确认“3.30”的含义：阶段编号、预计时间、时间点，或老师展示时的备注。
- [ ] 将完整路线拆分为步行、公交/地铁、换乘、到达等阶段。
- [ ] 每阶段显示名称、距离、预计时间、下一步操作和完成状态。
- [ ] 阶段完成后自动进入下一阶段，退出后可恢复当前阶段。
- [ ] 确认“3.30”含义后，再确定其最终展示位置和字段。

**验收标准：** 用户能清楚知道当前阶段、剩余阶段和各阶段时间，总时间与阶段时间逻辑一致。

## 三、P1：出行体验与无障碍

### 4. 无障碍完善

#### 路线规划

- [ ] 支持轮椅优先路线，避开楼梯、无电梯出入口和高路缘路段。
- [ ] 标识坡道、电梯、无障碍卫生间和无障碍入口。
- [ ] 支持轮椅、视障、听障、老年人、婴儿车等出行需求设置。

#### 导航与设施状态

- [ ] 提供清晰的转向、文字和语音播报。
- [ ] 标识无障碍通道的可用、维修中和暂不可用状态。
- [ ] 停车场标识无障碍车位，公交/地铁标识无障碍入口。
- [ ] 无障碍设施状态变化后同步影响路线规划。

**验收标准：** 开启无障碍需求后，路线筛选结果会真实变化，不只是增加标签。

### 5. “长辈模式”调整为“关怀模式”

- [ ] 确定最终名称（建议使用“关怀模式”）。
- [ ] 统一修改入口、按钮、提示和帮助文案。
- [ ] 放大文字、按钮和重点信息，减少同时展示的信息量。
- [ ] 增加高对比度，以及更明显的返回、取消、确认反馈。
- [ ] 保证关怀模式下路线、导航、停车、充电和反馈功能可用。

### 6. 关怀模式语音识别评估

- [ ] 评估浏览器和移动端的语音识别兼容性及第三方服务成本。
- [ ] 第一阶段优先实现语音搜索目的地。
- [ ] 后续评估语音添加途经点、停车查询和充电查询。
- [ ] 增加麦克风权限、识别中、识别失败和文字输入降级方案。
- [ ] 保留语音播报作为相对稳定的辅助能力。

## 四、P2：真实数据与动态状态

### 7. 交通路口拥堵

- [ ] 展示路口名称、拥堵等级和影响道路。
- [ ] 区分畅通、缓行、拥堵、严重拥堵。
- [ ] 将拥堵信息关联到路线推荐和预计时间计算。
- [ ] 显示数据更新时间，处理过期、接口失败和无数据状态。

### 8. 停车场数据真实化

- [ ] 接入真实数据，或建立与真实接口一致的动态模拟数据。
- [ ] 完善名称、地址、总车位、剩余车位、收费标准、营业时间等字段。
- [ ] 标识新能源车位、无障碍车位和当前空闲/拥挤/已满状态。
- [ ] 支持按距离、剩余车位和价格筛选，并可进入导航。
- [ ] 增加数据更新时间及停车场关闭、维护状态。

### 9. 充电桩数据真实化

- [ ] 完善充电站、充电桩编号、快慢充、功率、价格和服务费字段。
- [ ] 区分空闲、使用中、故障、维护中、离线状态。
- [ ] 支持按距离、价格、速度和可用状态筛选。
- [ ] 对编号、状态、价格等关键数据进行校验并显示更新时间。

### 10. 扫码充电

- [ ] 扫码后直接显示当前充电桩编号，无需用户再次输入。
- [ ] 展示充电枪编号、充电状态、功率和计费标准。
- [ ] 支持确认开始充电、查看进行中状态和结束充电。
- [ ] 结束后生成订单并展示电量、时长和费用。
- [ ] 处理扫码失败、编号不存在、被占用和故障等情况。

**验收标准：** 页面展示的编号来自扫码结果或后端返回，开始、进行中、结束状态能够正确流转。

## 五、P2：用户端与管理端闭环

### 11. 管理端实时处理并反馈用户端

- [ ] 管理端接收充电订单、停车异常、设施异常和用户反馈。
- [ ] 支持待处理、处理中、已处理、已关闭等状态。
- [ ] 支持分配、转派、驳回、关闭并填写处理结果。
- [ ] 记录处理人员、处理时间和处理内容。
- [ ] 用户端显示处理进度和最终反馈。
- [ ] 优先评估 WebSocket/SSE；不可用时提供定时刷新降级方案。

**验收标准：** 用户提交的问题能在管理端出现，管理端处理后用户端能看到状态和结果。

## 六、P3：碳积分与兑换

### 12. 碳积分规则

- [ ] 明确步行、骑行、公交、地铁、新能源汽车、拼车等获取场景。
- [ ] 将出行距离、交通方式减碳系数和激励系数纳入计算。
- [ ] 设置距离上限、异常行程、重复提交、取消行程和跨日规则。
- [ ] 明确积分到账时间并展示出行距离、减碳量和积分明细。
- [ ] 确保前后端使用同一套计算规则。

**公式示例：**

```text
碳积分 = 出行距离 × 交通方式减碳系数 × 用户激励系数
```

### 13. 碳积分兑换落地

- [ ] 建立商品/权益列表，展示积分价格、库存、有效期和兑换规则。
- [ ] 支持积分和库存校验、兑换下单、成功扣分和兑换记录查询。
- [ ] 处理积分不足、库存不足、重复提交和兑换失败回滚。
- [ ] 管理端支持商品上下架、积分价格、库存和兑换记录管理。

**验收标准：** 用户能够完成“获得积分 → 查看明细 → 兑换权益 → 查看记录”的完整流程，失败时不错误扣分。

## 七、P3：管理端所有模块完善

### 14. 首页与数据看板

- [ ] 展示用户、出行、路线、停车、充电、拥堵和碳积分指标。
- [ ] 支持按日期、区域和业务类型筛选。
- [ ] 展示数据更新时间、加载中、空数据和接口失败状态。

### 15. 用户与反馈管理

- [ ] 用户列表搜索、筛选、分页和详情查看。
- [ ] 查看出行、积分、兑换记录和用户反馈。
- [ ] 支持反馈工单分配、转派、处理、关闭和结果反馈。

### 16. 路线与交通管理

- [ ] 查看路线规划记录、热门路线和拥堵路口。
- [ ] 维护道路、路口、施工和临时管制状态。
- [ ] 修改后同步影响用户端路线和拥堵信息。

### 17. 停车场管理

- [ ] 停车场新增、编辑、删除、上下线和状态维护。
- [ ] 管理车位数量、收费规则、营业时间、新能源车位和无障碍车位。
- [ ] 查看停车场异常并记录管理员操作。

### 18. 充电桩管理

- [ ] 充电站和充电桩新增、编辑、删除、上下线。
- [ ] 管理编号、状态、功率、快慢充类型和收费标准。
- [ ] 处理故障、维护、离线状态和异常充电订单。

### 19. 无障碍设施管理

- [ ] 管理坡道、电梯、无障碍入口等设施的位置和状态。
- [ ] 处理用户上报的设施问题，并同步到无障碍路线。

### 20. 积分运营管理

- [ ] 配置交通方式、距离计算、积分上限和规则版本。
- [ ] 查看积分发放、消耗和兑换数据。
- [ ] 管理兑换商品、库存、上下架和异常积分。

### 21. 权限与操作日志

- [ ] 区分超级管理员、运营、客服和数据人员权限。
- [ ] 限制不同角色可访问和可修改的模块。
- [ ] 记录新增、修改、删除、上下线和关键配置变更。
- [ ] 记录操作人员、时间和操作内容。

## 八、推荐实施顺序

1. 途经点、多路线、距离/时间展示、扫码显示充电桩编号。
2. 停车场、充电桩、拥堵等基础数据及状态展示。
3. 分阶段导航和无障碍路线。
4. 管理端事件处理、用户端反馈和实时状态同步。
5. 碳积分计算、积分明细和兑换闭环。
6. 关怀模式、语音识别和管理端权限、日志、看板完善。

## 九、统一验收要求

- [ ] 所有页面具备正常、加载、空数据和错误状态。
- [ ] 前端展示字段与接口字段一致，并标注数据来源或更新时间。
- [ ] 关键流程完成“进入页面 → 发起操作 → 接口处理 → 成功反馈 → 刷新后数据仍存在”。
- [ ] 失败操作不会产生错误扣费、扣积分或重复订单。
- [ ] 用户端操作、管理端处理和最终反馈能够完整追踪。
- [ ] 关怀模式、桌面端和移动端布局均可正常使用。
